# Push this project to GitHub

Assuming your remote repository is already created and named:
`MeriumAbbasi/trustgraspnet-soft-spiral-grasp-assessment`

Run these commands from the project folder:

```bash
git init
git branch -M main
git add .
git commit -m "Initial project upload"
git remote add origin https://github.com/MeriumAbbasi/trustgraspnet-soft-spiral-grasp-assessment.git
git push -u origin main
```

If Git says the remote already exists:

```bash
git remote set-url origin https://github.com/MeriumAbbasi/trustgraspnet-soft-spiral-grasp-assessment.git
git push -u origin main
```
